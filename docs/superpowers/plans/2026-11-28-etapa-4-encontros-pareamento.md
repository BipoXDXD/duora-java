# Etapa 4 — Encontros públicos e privados, pareamento: plano de implementação

> **Para agentes:** sub-skill obrigatória: superpowers:subagent-driven-development (recomendado) ou superpowers:executing-plans. Passos com checkbox (`- [ ]`). Implementadores usam `superpowers:test-driven-development` ou `mattpocock-skills:tdd`; antes de "pronto", `superpowers:verification-before-completion` e `duora-etapa`.

**Objetivo:** quem tem conta `ATIVA` abre um encontro público (fila contínua, pareado a cada ciclo com alguém compatível nos dois sentidos, sem vetos e dentro da capacidade, com cenário inédito sorteado) ou privado (convite de uso único com escolha de cenário); a espera mostra posição, tempo típico e horários com mais gente; tempo real por SSE e aviso opcional por Web Push sem dado pessoal na tela bloqueada.

**Arquitetura:** três módulos novos com as camadas da 2a/3 travadas pelo `ArquiteturaTest` (raiz = API pública; `dominio/` Java puro; `infra/` JDBC; `web/` controllers): `pareamento/` (tipos do par, vetos e a fachada `Pareamento`; `Compatibilidade` e `Pareador` puros em `dominio/`), `sala/` (fila, ciclo, portas do encontro, cenários, convite privado, liquidez, aviso de compatível) e `eventos/` (gravação em `evento_conta` com `seq` e lock por conta, SSE em `eventos/web/`), mais `push/` (H1). `room/` implementa as portas de `sala` (`PonteDeEncontros`) até a Etapa 5. Dependências: `sala → pareamento, perfil, conta, game, eventos, push, web`; `room → sala, pareamento, perfil`; `push → conta, notificacao`; `eventos → conta`. Ninguém depende de `room`. No front, `fe/eventos/` (canal único por aba), `fe/telas/encontrar/`, `fe/notificacao/` e o SW com `push`.

**Stack:** Java 25, Spring Boot 4.2 (Spring Framework 7: `SseEmitter`, `TransactionSynchronization`), PostgreSQL 18/Flyway (`FOR UPDATE SKIP LOCKED`, `pg_try_advisory_xact_lock`, `pg_advisory_xact_lock`), `JdbcClient`, `com.interaso:webpush:1.3.0` (H5), Micrometer; React 19 + TS + React Router 7.18.6 + TanStack Query 5.108.1 + valibot 1.5.0, Vitest, Playwright Java 1.65.1.

**Spec:** `docs/superpowers/specs/2026-11-21-duora-social-design.md` (Etapa 4, linhas 178–190; "Paridade com o mercado", linhas 62–64; linha 147 sobre o cenário inédito). **Contratos (valem sobre este plano):** `docs/superpowers/plans/2026-11-22-contratos-entre-etapas.md`. **Origem:** substitui `docs/superpowers/plans/2026-11-22-etapa-4-salas-pareamento.md`. **Base:** `etapa-3` mergeada; branch `etapa-4`.
